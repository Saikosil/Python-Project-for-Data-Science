# Python-Project-for-Data-Science

Covering the role of a Data Scientist / Data Analyst for a new startup investment, the goal is to help customers invest their money in stocks.
The job is to extract financial data, like historical share price and quarterly revenue reportings, from various sources using Python libraries and webscraping on popular stocks.
After the collection of the data, they will be visualized in a dashboard to identify patterns or trends.
The stocks worked with are Tesla, Amazon, AMD, and GameStop.
